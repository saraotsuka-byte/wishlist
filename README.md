# 消耗品ストック管理アプリ

洗剤・シャンプー・ティッシュ・トイレットペーパーなど、日用消耗品の在庫を管理し、「何を、いつ、どれだけ買うべきか」をひと目で分かるようにするアプリです。買い忘れ・買い過ぎ・ストック切れを防ぐことが目的です。

- データはすべて端末内（IndexedDB）に保存されます。サーバーやアカウント登録は不要です。
- スマホでの片手操作を想定したモバイルファーストUIですが、PCでも利用できます。
- ホーム画面に追加してオフラインでも使えるPWAです（フェーズ4で対応予定）。

## セットアップ

Node.js（推奨: v20以上）がインストールされていれば動作します。PowerShellでの実行を想定しています。

```powershell
npm install
npm run dev
```

`npm run dev` の実行後、ターミナルに表示されるURL（例: http://localhost:5173 ）をブラウザで開いてください。

## 主なコマンド

```powershell
npm run dev      # 開発サーバーを起動
npm run build    # 型チェックとビルド（本番用ファイルは dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
npm test         # ユニットテストを実行

```

## 初回起動時

カテゴリが1件も登録されていない状態でアプリを開くと、「サンプルデータを入れて始める」か「空の状態で始める」かを選ぶ画面が表示されます。どちらを選んでも、キッチン・洗面バスなど既定の7カテゴリが用意されます。

## 使い方の概要

1. **品目タブ**で、普段購入している消耗品を登録します（名前・カテゴリ・単位・在庫・発注点・標準購入数など）。
2. 在庫が減ったら、品目一覧または品目詳細の「－」ボタンで在庫を減らします（使用記録として保存されます）。
3. 在庫が発注点以下になると、自動的に**買い物リスト**に表示されます（この機能は今後のフェーズで実装予定です）。
4. **設定タブ**でカテゴリを追加・編集・削除できます。

## データについて

- すべてのデータは、今お使いのブラウザのIndexedDB内に保存されます。ブラウザのデータを消去すると失われるため、必要に応じてバックアップ機能（今後のフェーズで実装予定）をご利用ください。
- 別の端末にデータを引き継ぐ機能（JSONバックアップ/復元）は今後のフェーズで追加予定です。
