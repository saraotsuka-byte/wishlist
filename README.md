# 消耗品ストック管理アプリ

洗剤・シャンプー・ティッシュ・トイレットペーパーなど、日用消耗品の在庫を管理し、「何を、いつ、どれだけ買うべきか」をひと目で分かるようにするアプリです。買い忘れ・買い過ぎ・ストック切れを防ぐことが目的です。

- データはすべて端末内（IndexedDB）に保存されます。サーバーやアカウント登録は不要です。
- スマホでの片手操作を想定したモバイルファーストUIですが、PCでも利用できます。
- ホーム画面に追加してオフラインでも使えるPWAです。
- ダークモードはOSの設定に自動で追従します。

## セットアップ

Node.js（推奨: v20以上）がインストールされていれば動作します。PowerShellでの実行を想定しています。

```powershell
npm install
npm run dev
```

`npm run dev` の実行後、ターミナルに表示されるURL（例: http://localhost:5173 ）をブラウザで開いてください。

## 主なコマンド

```powershell
npm run dev      # 開発サーバーを起動
npm run build    # 型チェックとビルド（本番用ファイルは dist/ に出力。Service Worker/マニフェストも生成）
npm run preview  # ビルド結果をローカルで確認（PWAの動作確認はこちらで行う）
npm test         # ユニットテストを実行
npm run lint     # 静的解析（oxlint）
```

## 初回起動時

カテゴリが1件も登録されていない状態でアプリを開くと、「サンプルデータを入れて始める」か「空の状態で始める」かを選ぶ画面が表示されます。どちらを選んでも、キッチン・洗面バスなど既定の7カテゴリが用意されます。

## 使い方の概要

1. **品目タブ**で、普段購入している消耗品を登録します（名前・カテゴリ・単位・在庫・発注点・標準購入数・よく買う店・参考価格など）。
2. 在庫が減ったら、品目一覧または品目詳細の「－」ボタンで在庫を減らします（使用記録として保存され、消費ペースの予測に使われます）。
3. 在庫が発注点以下になった品目や、使用ペースから7日以内に切れそうな品目は、自動的に**買い物リスト**に表示されます。手動で品目を追加することもできます。
4. 買い物リストは店舗ごとにグルーピングされます。買い終えたらチェックを入れて「購入完了」を押すと、在庫の加算・購入履歴の記録・リストからの削除が一度に行われます。
5. **ホームタブ**では「今すぐ買うべき」「そろそろ買う」「十分ある」の3区分で状況を一覧でき、カテゴリ・名前での絞り込みと、月ごとの支出グラフを確認できます。
6. **設定タブ**でカテゴリ・店舗の管理、データのバックアップ／復元、購入履歴のCSV出力ができます。

## データについて

- すべてのデータは、今お使いのブラウザのIndexedDB内に保存されます。ブラウザのデータを消去すると失われるため、定期的に設定タブから「バックアップをJSONでダウンロード」しておくことをおすすめします。
- 別の端末に引き継ぎたい場合は、ダウンロードしたJSONファイルを新しい端末の「バックアップから復元」で読み込んでください。**復元すると、復元先の端末に保存されていたデータはすべて上書きされます**（取り消せません）。
- 購入履歴は設定タブから「購入履歴をCSVでエクスポート」でダウンロードできます（Excelでもそのまま開けます）。
